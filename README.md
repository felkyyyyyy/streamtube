# StreamTube — YouTube Clone Platform

Полнофункциональная платформа видеохостинга (копия YouTube), разработанная на стеке **Python + FastAPI + PostgreSQL + Redis + MinIO (S3) + FFmpeg + React (TypeScript + Tailwind CSS)** с развертыванием на чистой Ubuntu **одной командой**.

---

## Быстрый запуск на чистой Ubuntu (одна команда)

```bash
bash deploy.sh
```

*(или с кастомным портом: `APP_PORT=8080 bash deploy.sh`)*

Скрипт `deploy.sh` полностью идемпотентен и автоматически:
1. Устанавливает Docker Engine и Docker Compose plugin (если отсутствуют).
2. Генерирует `.env` с криптостойкими случайными секретами (`openssl rand -hex 32`).
3. Собирает и запускает все сервисы: **PostgreSQL 16**, **Redis 7**, **MinIO (S3)**, **FastAPI backend**, **FFmpeg background transcoder worker**, **Nginx + React SPA**.
4. Выполняет миграции БД (**Alembic**).
5. Наполняет базу демо-данными (`seed.py`) и генерирует через FFmpeg реальные воспроизводимые HD-видео (MP4 + адаптивные HLS-потоки + превью).
6. Выполняет smoke-проверки `/api/v1/health`, `/docs` и `/api/v1/videos`.

### Точки входа после деплоя
- **Веб-приложение:** `http://<server-ip>/`
- **Swagger UI (OpenAPI):** `http://<server-ip>/docs`
- **Healthcheck:** `http://<server-ip>/api/v1/health`

## Реализованная функциональность

### Экраны (YouTube-подобный UI)
- **Главная (`/`)** — сетка видео с превью, длительностью, аватарами каналов, фильтрами по категориям, сортировкой (новые / популярные), а также ленты `/subscriptions`, `/shared` (приватные видео, доступные мне), `/studio` (мои видео).
- **Просмотр видео (`/watch/:id`)** — адаптивный плеер **HLS.js** с мгновенным фоллбэком на **HTTP 206 Range streaming**, лайки/дизлайки, подписка на канал, раскрываемое описание, древовидные комментарии (с ответами и удалением), сохранение в плейлисты, жалобы, управление доступом к приватным видео, колонка рекомендаций.
- **Канал (`/channel/:handle`)** — баннер, профиль, подписка, вкладки **Видео**, **Плейлисты** (создание, добавление/удаление видео, просмотр), **О канале**.
- **Поиск (`/search?q=...`)** — горизонтальные карточки результатов по названию, описанию, тегам и имени канала с сортировкой.
- **Загрузка (`/upload`)** — drag-and-drop выбор файла и кастомного превью, реальный прогресс-бар (`XMLHttpRequest`), выбор видимости (`public` / `unlisted` / `private`), указание пользователей для приватного доступа, отслеживание статуса транскодирования.
- **Вход и регистрация (`/login`, `/register`)** — Argon2id + JWT + ротируемые HttpOnly Refresh-токены.
- **Модерация (`/moderation`)** — очередь жалоб (`Hide Video` / `Dismiss`), список скрытых видео (`Restore`), неизменяемый журнал аудита, панель администратора для управления ролями.

### Сценарий быстрой проверки («Регистрация → Загрузка → Просмотр → Лайк → Комментарий»)
1. Откройте `/register` и создайте новый аккаунт.
2. Перейдите в `/upload`, выберите любой `.mp4` / `.webm` файл, укажите название и нажмите **Publish Video**.
3. Нажмите **Watch Video Now** — видео доступно мгновенно (через HTTP Range, а после завершения фонового FFmpeg-воркера автоматически переключается на адаптивный HLS).
4. Поставьте лайк и оставьте комментарий под видео.

## Запуск автотестов

Внутри Docker-контейнера:
```bash
docker compose exec backend pytest -v
```

Локально (без Docker, используя встроенный SQLite + LocalStorage тестовый контур):
```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pytest -v
```

Покрытие тестов (`backend/tests/`):
- Регистрация, вход, ротация refresh-токенов, отзыв при выходе (`test_auth_and_rbac.py`)
- Границы RBAC (`user` / `moderator` / `admin`) и запрет саморазжалования (`test_auth_and_rbac.py`)
- Сквозной сценарий: регистрация → загрузка → Range 206 стрим → просмотр → лайк → комментарий (`test_videos_and_privacy.py`)
- Защита загрузки: отклонение поддельных `.mp4` (magic bytes) и запрещённых расширений (`test_videos_and_privacy.py`)
- Приватные видео: запрет для анонимов и чужих пользователей, доступ по гранту, **мгновенный отзыв ранее подписанного URL** после снятия доступа (`test_videos_and_privacy.py`)
- HLS-манифесты с подписью сегментов и защита от Path Traversal (`test_videos_and_privacy.py`)
- Каналы, подписки, поиск, плейлисты (`test_social_features.py`)
- Жалобы, скрытие/восстановление видео, аудит-логи, security-заголовки, Swagger `/docs`, идемпотентность сидера (`test_moderation_and_security.py`)
